# AGENTS.md

Guidance for AI coding agents working in `board-game-collection`.

## Repository Overview

This repository catalogs a personal board game collection and pairs each game with a concise **Quick-Start Guide** and optional **SVG setup/turn-flow schematic**, published to GitHub Pages via MkDocs Material.

### Key Paths
- `README.md` — Master collection index and progress summary (auto-generated by `scripts/sync_collection.py`).
- `data/collection.csv` — Local mirror of the Google Sheet catalog (`Shelf`, `Position`, `Game Title`, `Box Title / Localized`, `Type`, `Players`, `Play Time`, `Guide Status`, `GitHub Doc Slug`, `Notes`).
- `guides/*.md` — Individual game quick-start guides.
- `assets/*-schematic.svg` — Visual setup/turn-flow schematics embedded in guides.
- `templates/quick-start-template.md` — Standardized template for new guides.
- `scripts/sync_collection.py` — Syncs `data/collection.csv` from a published Google Sheet CSV (or `--local`), creates missing `guides/*.md` stubs, and regenerates `README.md`.
- `mkdocs.yml` — MkDocs Material configuration (`docs_dir: docs`).
- `.github/workflows/pages.yml` — GitHub Pages workflow; stages `docs/` from `README.md`, `guides/`, and `assets/` before running `mkdocs build --site-dir site`.

## Environment & Common Commands

This repo uses `uv` for Python dependency management (`pyproject.toml` + `uv.lock`).

```bash
# Install dependencies (including dev tools: pre-commit, ruff)
uv sync

# Sync README.md and missing guide stubs from local data/collection.csv
uv run python scripts/sync_collection.py --local

# Sync from a published Google Sheet CSV URL
uv run python scripts/sync_collection.py --url "<PUBLISHED_CSV_URL>"

# Run pre-commit hooks across all files
uv run pre-commit run --all-files
```

## Authoring & Editing Conventions

1. **Guides (`guides/*.md`):**
   - Follow the structure and YAML frontmatter in `templates/quick-start-template.md` (`title`, `box_title`, `type`, `players`, `play_time`, `shelf`, `position`, `status`).
   - Keep guides concise and tabletop-ready (Objective, Setup, Turn Structure, Key Rules & Edge Cases, End-Game & Scoring).
   - When adding a schematic, save it to `assets/<slug>-schematic.svg` and reference it in the guide as `../assets/<slug>-schematic.svg`.
   - Update the game's `Guide Status` in `data/collection.csv` (or the source Google Sheet) and `status` in the guide frontmatter when completing a guide.

2. **Catalog & `README.md`:**
   - Do not hand-edit the Game Catalog table or progress counts in `README.md`; edit `data/collection.csv` (or sync from Google Sheets) and run `uv run python scripts/sync_collection.py --local`.

3. **MkDocs & GitHub Pages:**
   - `mkdocs.yml` sets `docs_dir: docs`. Do **not** commit a `docs/` or `site/` directory; `.github/workflows/pages.yml` stages `docs/index.md`, `docs/guides/`, and `docs/assets/` during CI.
   - To preview locally, stage `docs/` or copy into `docs/`, run `uv run mkdocs serve`, and clean up `docs/` before committing.

4. **Code Quality:**
   - Format and lint Python changes (`scripts/sync_collection.py`) with `ruff` via `uv run pre-commit run --all-files`.
